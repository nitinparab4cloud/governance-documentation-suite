Governance Documentation Suite

One YAML/JSON spec in, six governance documents out — Model Card, Risk Assessment, Data Governance Statement, Human Oversight Design, Incident Response Runbook, and Vendor AI Risk Questionnaire — rendered from the same source of truth so they can never disagree about what the system is. This static demo is a dependency-free JS port of the Python generator (generate.py); everything runs in your browser, no server, no network calls.

Running self-tests…

Fill in the form below (prefilled with a worked example — the unitary/toxic-bert content-moderation classifier) and click Generate. Everything runs in your browser: the form builds the same structured spec the Python version takes as YAML, then renders all six documents from it. Use the "+ Add" / red buttons to add or remove list items (affected parties, mitigations, metrics, etc.).

Advanced: import / export as JSON

Already have a spec as JSON (e.g. from the field-reference spreadsheet)? Paste it below and load it into the form. Or export what the form currently holds to copy elsewhere.

How the overall risk level is computed

Probability of harm × severity if it occurs → one of four levels. Deliberately simple: a reviewer should be able to sanity-check this table in ten seconds, which is the point of a visible matrix instead of an opaque score.
